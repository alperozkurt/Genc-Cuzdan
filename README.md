[EN] This mobile FinTech project enhances the financial literacy of middle school, high school, and university students. The platform enables users to monitor earnings and spending while developing target-based saving strategies.

[TR] Bu mobil FinTech projesi, ortaokul, lise ve üniversite öğrencilerinin finansal okuryazarlığını artırır. Platform, kullanıcıların kazanç ve harcamalarını izlemesini sağlarken hedef tabanlı tasarruf stratejileri geliştirmesine yardımcı olur.
